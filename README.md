# ⛏️ CryptoMiners - Global Cloud Mining & VIP Staking Platform

Luxury **White, Golden, Off-White & Pearl** themed Cloud Mining & Yield Investment Platform. Built with modern Node.js/Express, zero-dependency JSON database persistence, live multi-QR UPI & Crypto gateway rotation, and an Executive Master Admin Panel.

---

- **Luxury Theme & Aesthetics**: Built with high-end White (`#FFFFFF`), Off-White (`#FAF9F6`), Slate (`#0F172A`), and Golden gradients (`#D4AF37`, `#F59E0B`). Crisp SVG coin medallions for Bitcoin (BTC), Ethereum (ETH), Tether (USDT), Solana (SOL), and Binance Coin (BNB).
- **Cloud Mining Rig Plans**: Preloaded with 6 realistic cloud mining rigs (BTC Starter, ETH Staking Node, USDT Yield Hive, Antminer S21 Pro Hydro, Solana Cluster, Genesis AI Hive). Full support for custom Coin badges, Hashrate power, cycle days, and daily returns.
- **Master Executive Admin Portal (`/admin`)**:
  - Live deposit verifications with 12-digit UTR & Crypto TXID verification.
  - Withdrawal approvals & instant refund on rejection with custom notes.
  - Multi-QR Gateway Auto-Rotation Pool (Round-Robin switching across PhonePe/GPay/Paytm + USDT TRC-20 & BEP-20 addresses).
  - Mining Plans Manager (Add / Edit / Toggle / Delete rigs with live image & coin selection).
  - Registered Miners Directory with balance credit/debit and ban controls.
  - Manual financial ledger adjustments and CSV/JSON export.
- **Interactive Miner Engagement**:
  - Daily 18:00 IST mining yield harvest counter.
  - Lucky Hashrate Spin Wheel with instant cash rewards.
  - Daily Attendance Check-In bonus.
  - 3-Level Team Referral Program (Level 1: 40%, Level 2: 3%, Level 3: 1%).

## 🚀 Quick Start Guide

### 1. Install Dependencies
```bash

```

```bash

# Server starts on port 3000 (or process.env.PORT)
```

### 3. Open in Browser
- **Client Mining App**: `http://localhost:3000`
- **Executive Admin Dashboard**: `http://localhost:3000/admin`
